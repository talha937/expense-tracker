# Security Policy

## Supported Versions

This project is actively maintained on the default branch.

## Reporting a Vulnerability

Please report security vulnerabilities privately.

Preferred options:
1. Open a private security advisory via GitHub Security Advisories.
2. If advisory flow is unavailable, open a GitHub issue with minimal details and request a private follow-up.

Please include:
- Affected area (backend/frontend/API)
- Reproduction steps
- Potential impact
- Suggested remediation (if known)

We aim to acknowledge reports within 3 business days and provide an initial remediation plan within 7 business days.
